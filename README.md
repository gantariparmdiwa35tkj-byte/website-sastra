## 🚀 Panduan Upload / Deploy ke Vercel (Gratis & Cepat)

Website ini adalah **Static Web Modern (HTML5, CSS3, JavaScript)** sehingga dapat langsung di-deploy di Vercel dalam hitungan detik tanpa build error.

### Cara 1: Deploy Lewat GitHub (Sangat Direkomendasikan)
1. Buat repository baru di akun GitHub kamu (misal: `atrssasaw-web`).
2. Masukkan (push) semua isi folder `atrssasaw-web` ke repository GitHub tersebut:
   ```bash
   git init
   git add .
   git commit -m "Initial commit website atrssasaw"
   git branch -M main
   git remote add origin https://github.com/USERNAME-KAMU/atrssasaw-web.git
   git push -u origin main
   ```
3. Buka [https://vercel.com](https://vercel.com) dan login dengan akun GitHub kamu.
4. Klik tombol **"Add New..."** -> **"Project"**.
5. Pilih repository `atrssasaw-web` yang baru saja dibuat, lalu klik **"Import"**.
6. Pada bagian **Framework Preset**, biarkan **"Other"**.
7. Klik **"Deploy"**! Dalam 15-30 detik website kamu sudah live dengan domain gratis seperti:
   `https://atrssasaw-web.vercel.app` 🎉

---

### Cara 2: Deploy Lewat Vercel CLI (Langsung dari Terminal)
1. Buka terminal (PowerShell atau Command Prompt) di folder `atrssasaw-web`.
2. Jalankan perintah:
   ```bash
   npx vercel
   ```
3. Ikuti panduan di layar:
   - Ketik `y` untuk konfirmasi setup.
   - Pilih scope akun Vercel kamu.
   - Link to existing project? ketik `n`.
   - What's your project's name? ketik `atrssasaw` (atau tekan Enter).
   - In which directory is your code located? tekan Enter (`./`).
4. Selesai! Vercel akan langsung memberikan link website aktif kamu.

---

### Cara 3: Drag & Drop ke Vercel Dashboard
1. Buka dashboard [vercel.com](https://vercel.com).
2. Tarik (drag & drop) seluruh folder `atrssasaw-web` ke area dashboard Vercel.
3. Website akan otomatis di-upload dan langsung aktif!

## 💻 Menjalankan di Komputer Lokal (Preview)

Kamu bisa langsung klik dua kali file `index.html` untuk membukanya di browser apa pun (Google Chrome, Edge, Safari), atau menggunakan live server:
```bash

```
